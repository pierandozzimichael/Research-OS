# Demo Evidence Workspace

This vault is synthetic and contains no real scientific evidence. Use it to
learn navigation, branching, graph filtering, Markdown editing, and AI handoff
before connecting a real lab project.

## Suggested tour

Open the paper, follow its claim, inspect the hypothesis, then open the proposed
experiment. The records are intentionally small so a new user can understand
the relationship model in a few minutes.
